# Scientific Task Types

`ScientificTaskType` is the cross-domain task vocabulary used by Domain Packs and generic agents.

Current types:

- `theory_derivation`
- `numerical_modeling`
- `data_extraction`
- `experiment_selection`
- `phase_identification`
- `hidden_answer_benchmark`
- `material_comparison`

Each type has a deterministic policy with required stages, success criteria, stopping conditions, and expected artifacts. These policies are intentionally lightweight in this checkpoint.
