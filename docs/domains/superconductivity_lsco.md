# Superconductivity LSCO Domain Pack

Status: fixture and existing LSCO Phase 2 adapter implemented through the existing superconductivity acquisition pipeline.

Capabilities:

- LSCO query templates
- observable ontology adapter
- Phase 1 BCS tool descriptors
- Phase 2 acquisition descriptor
- readiness gates
- guardrails against material-level overclaiming

Limitations:

- Live PDF/XLSX/table extraction remains partial.
- Figure-only optical data require reviewed digitization.
- Material-level comparison remains blocked unless coverage, provenance, overlap, and held-out gates pass.
