# V3.0 Development Note

This checkpoint implements a proof-carrying state foundation for bounded scientific search.

Implemented:

- strict V3 schemas and state machine;
- exact artifact support validation;
- immutable scientific-state snapshots;
- unsupported completion detection;
- deterministic state-dispute adjudication;
- tool capability registry and tool-gap records;
- conservative validated-tool registration path;
- bounded finite representation-dependence counterexample demo;
- CLI and frontend adapters;
- Live Agent Room round-zero integration for decomposition/gauge/observability questions;
- regression tests for the observed V2.8 epistemic-state failures.

Not implemented as a full production system:

- arbitrary generated-tool source execution;
- full sandboxed dependency management;
- complete exact diagonalization package for general spinful lattices;
- general theorem proving;
- database migration layer for persistent V3 tables;
- live-model proposal gating beyond the current deterministic adapters.

Scientific limitation:

The V3 demo result is labeled `FINITE_CASE_ONLY`. It shows that a bounded finite fixture can preserve total physical predictions while changing sector partitions. It must not be described as a general theorem for all superconducting lattice models.
