# Phase 2 Provenance

Every promoted LSCO data row must be traceable to a candidate row and extraction record. Required provenance includes:

- paper identifier
- DOI, arXiv ID, or OpenAlex ID where available
- source URL
- page, table, or figure identifier where available
- evidence text or digitization provenance
- extractor version
- validation decision

Discovery is not evidence. A paper must move through discovery, relevance classification, extraction, normalization, validation, and promotion before it can support a material-level claim.
